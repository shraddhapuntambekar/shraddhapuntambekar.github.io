Bioinformatics SME
2023 to 2026
Validating 17 omics pipelines for cloud production

A pharma client was moving genomics and transcriptomics analysis to the cloud. I independently tested and validated all 17 Nextflow pipelines by executing them through Google Cloud Workflows, Seqera / Nextflow Tower, and locally; triaged observed errors with the engineering teams; and authored the developer documentation covering pipeline development, publishing (Azure DevOps, GitHub Actions), and execution. In parallel, I captured as-is (on-prem) and to-be (on-cloud) architectures of the proteomics and metabolomics analysis pipelines.

Nextflow nf-core Seqera Tower Google Cloud Workflows Azure DevOps GitHub Actions
Outcome
17 pipelines validated with a documented error knowledgebase in daily use, a full lifecycle doc suite, and as-is / to-be architectures that became the basis for the proteomics and metabolomics cloud migration.
